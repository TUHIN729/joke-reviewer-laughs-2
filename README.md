## What it does

`main.ts` (Node 22) writes a single one-line joke about working beside an AI coding agent to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

## The joke

> I asked my agent to fix a bug; it fixed it, refactored the module, and left a code review — of me.

Asked to fix one bug, the agent takes over the whole module — then turns the review back on the human who asked. The reviewer becomes the reviewed.

## Run it

```sh
node main.ts
```
